# Phase 1 — Charter-Cycle Pre-Mortem (failure scenarios)

**Arc:** cairn-identity `/decision` (2026-05-30). **Posture:** HARDEN + ATTACK.
**Frame:** assume the charter cycle SHIPPED as the identity-ADR methodology. It is now 6–12 months later and it has FAILED. These are the obituaries.
**Inputs:** `00-lead-findings.md` (F1–F8), `02-journey-trace.md` (Gaps 1,2,3,6), `brainstorm-1-charter-cycle.md`, `landscape.md` (C1–C8, residual cliff, Kim et al.), repo reality (39 ADRs; gh:#33 OPEN; L-016/L-019/L-020 consumer incidents).

**Method:** weighted toward dimensions the boundary-focused journey trace under-covered — TEMPORAL/multi-cycle, SCALE, INTEGRATION, CORRELATED-ERROR, IDENTITY/one-way-door. Each scenario builds PAST the four journey-trace gaps rather than rehashing them; where a scenario amplifies a known gap across time/scale, it is flagged AMPLIFIES; genuinely new failure modes are flagged NEW. Mechanism claims are grounded against actual repo state, not the design's claims about it.

**Severity legend:** high = identity-ADR must be superseded / substrate corrupted / consumer broken; med = headline value silently lost or methodology decays to ad-hoc; low = friction / recoverable-by-operator-skill.

## S1 — Headline value proves unmeasurable; the identity ADR becomes a one-way door defended by prose. **[IDENTITY / one-way-door] — high × high — NEW**

The ADR ships, canonizing "goal-commitment vs reactivity" as a CO-EQUAL value alongside the cliff thesis (the operator-set "complement" position). Twelve months on, nobody can produce a measurement that the charter cycle reduced input-reactive over-steering, because the failure mode it targets — "the agent whipsawed on my message" — is a *counterfactual* about a single operator's sessions with no baseline and no instrument (F8: C1 unmeasured in cairn; the new headline is even softer). The re-injection hook (Gap 1) was shipped as a `UserPromptSubmit` emitter, but whether it changed behavior is unfalsifiable — the operator cannot run the same cycle twice. Meanwhile the ADR superseded 3 FIRM ADRs + retired INV-003 (F1), so the append-only cost is paid and irreversible. The identity claim now rests entirely on prose discipline (F3), exactly R2's surviving objection (F8): more firm state committed on evidence no more settled. **Earliest signal:** the first retrospective / handoff that wants to *justify* the charter cycle cites only the design doc and "it feels less whippy," with zero before/after metric — and a new `/decision` arc opens to re-litigate the identity question (identity-and-scope-deferral R1's predicted "fourth direction doc"), now needing to UNWIND 3 firm supersessions. This is the pre-mortem's headline: the one-way door swings on an unmeasurable hinge.

## S2 — Cross-cycle ADR↔code drift forms anyway; per-cycle goal-commitment never addressed the corpus-level cliff. **[TEMPORAL / multi-cycle] — high × high — NEW**

The charter cycle is a *within-cycle* discipline: it commits one `goal:`/`done:` and defends it against per-message reactivity for the life of one work-unit. But landscape.md is explicit that cairn's actual cliff (C1, residual leg #2) forms ACROSS THE SLICE CORPUS over months — ADR↔code semantic drift "lives ABOVE any single subagent dispatch." Over 6–12 months and ~40→60 ADRs, the meaning of an ADR drifts away from the code while the structural cross-reference still passes the validator (C6's own admitted hole: "prose meaning shifts while the structural cross-ref still passes" — unsolved in cairn too). The charter cycle did NOTHING about this — each cycle is goal-committed in isolation, and the across-cycle coherence the design hand-waves as "constraints compound" (§7 Out) is just `constraints:` *citations*, not semantic alignment (which §7-tier-3 NEVER mechanizes, and F7 confirms is architecturally unmechanizable under the closed validator whitelist). So cairn shipped a methodology whose headline defends a within-cycle failure mode while its load-bearing identity (the cliff, C1) is a CROSS-cycle failure mode the cycle structurally cannot touch. **Earliest signal:** a constraint-harvest worker (S7) cites an ADR as a binding `constraint:` whose prose no longer matches the code it governs, and a build proceeds "compliant" against a stale invariant — the validator stays green throughout. The drift is invisible until an operator manually reads an old ADR and finds it describes code that no longer exists.

## S3 — `done:`-singularity judgment + same-model verify silently rubber-stamps; the verify-worker certifies the build-worker's shared weights-level blind spot. **[CORRELATED-ERROR] — high × med-high — NEW**

The ONE mandatory cleave is build≠check (§8): the verifier is blind to the builder's reasoning and sees only the committed result + `done:`. The design sells this as cairn's defensible core (arc A C2). But landscape.md is brutally clear (residual leg #1, Kim et al. ICML 2025): a same-model fresh-context reviewer shares ~60% weights-level blind spots with the builder — "fresh-CONTEXT review removes within-session contamination but NOT shared-weights blind spots," and "neither cairn nor native primitives ENFORCE cross-model review." So build≠check buys ROLE-PURITY, not error-DECORRELATION. Concretely: build-worker (opus) misreads `done:` in a way its weights make natural; verify-worker (also opus, blind to reasoning but same model) reads the same `done:` the same wrong way, runs the validator (green — structural only), and returns "done: met." This is precisely L-016 ("Verdict-OK-but-bugs-present — Phase 4 success is local-only, not user-intent-correct"), which already FIRED on the downstream consumer (complex-rag-analysis: Phase 4 reported OK, operator's manual replay found bugs the codified verification could not assert). The charter cycle removes the 4-phase Auditor *and* the human role-reset half (C2, unfalsifiable) and replaces them with one same-model blind verifier — strictly less decorrelation than the machinery it supersedes. **Earliest signal:** the first cycle that closes green (validator pass + verify-worker "done: met") but the operator, manually exercising the `done:` condition, finds it unsatisfied — exactly L-016's shape, now with no Auditor phase to have caught it.

## S4 — Concurrent worktree-per-charter cycles corrupt shared `.claude/` state — L-019 at charter scale. **[SCALE / INTEGRATION] — high × med — AMPLIFIES Gap 2 + NEW(L-019)**

Open-question #5 resolves to worktree-per-charter (P4 parallelism-v1 maps worktree-per-slice → worktree-per-charter). The journey trace's Gap 2 (no per-worker write-scope; only the worktree-global operator envelope fires) was framed within ONE cycle. At scale it is worse and *mechanical*: L-019 ("Concurrent orchestrators sharing one `.claude/` tree") already documents a live incident where a concurrent consumer orchestrator corrupted `.claude/orchestrator-debug/` mid-pipeline, and L-019's anti-pattern signals explicitly reject "we just won't run two at once" as treating a mechanical hazard as a discipline question. Now make the charter a committed file under `.claude/` (§3 default) re-injected per turn by a hook (Gap 1's fix): two concurrent charter cycles, two leads, two hooks each reading/emitting charter state, with NO global active-cycle pointer (P4 D2 forbids one) and NO per-worker path confinement (Gap 2). Cycle A's build-worker, scoped in prose to its own charter file, writes — under the worktree-global envelope — to a path cycle B's hook reads, and B's re-injection now emits a corrupted/cross-contaminated goal. The reactivity failure the cycle exists to kill returns through a *concurrency* door the design never modeled. **Earliest signal:** the first two-cycle-concurrent session where one lead's re-injected `goal:` contains content from the other's charter or `amendments:` log; or a charter file write races a hook read and the hook emits a half-written goal. Mechanically reachable the moment two cycles run, per L-019.

## S5 — `amendments:` log grows unbounded / charter-form discipline rots over N cycles of single-operator rigor. **[TEMPORAL / SCALE] — med × high — AMPLIFIES Gap 4**

The `amendments:` log is append-only and narrative-by-nature (F8 open seam; the journey trace's Gap 4 noted the `done:`-singularity is declared-not-derived and operator-rubber-stampable). Across a long-running or frequently-amended cycle, the log grows monotonically, and the §6 re-injection hook emits `goal:` + ALL open `amendments:` *every turn* — so a cycle with 15 amendments re-injects a 15-entry narrative each turn, the exact context-bloat INV-007/context-tiers-integration exists to prevent (F8 warns the re-injection must not bloat or smuggle reasoning across the worker boundary). Worse, this is single-operator discipline with no second pair of eyes: over 6 months the operator, under delivery pressure, rubber-stamps two-goal charters ("ship X + document X" — Gap 4's fuzzy case), folds genuine pivots as "elaboration" to avoid the amendment ceremony, and lets `done:` conditions get fuzzier ("works well" instead of a testable line). The crystallization SMART-gate and single-`done:` are operator judgment with no mechanism (F7: semantic alignment unmechanizable). The methodology decays from the inside to a glorified TODO with a stale narrative header, indistinguishable from the ad-hoc path it replaced. **Earliest signal:** a charter whose `amendments:` log exceeds the re-injection budget (hook output truncates or blows context); or a closed cycle whose `done:` was non-testable prose — the SMART-gate having been waved through under time pressure. The first amendment recorded as "(see chat)" instead of a reason is the canary.

## S6 — Migration straddle: 5 superseded ADRs' live machinery coexists with the half-built charter cycle; the seam breaks the downstream consumer. **[INTEGRATION] — high × med — NEW**

The identity ADR supersedes 5 ADRs + retires INV-003 *on paper* (F1), but the charter cycle's mechanisms ship as BUILD DELIVERABLES across multiple follow-up slices (Gap 1's hook, Gap 2's per-worker scope, the charter-formation skill, the amendment skill). During the straddle — which lasts months, not days — the repo holds BOTH the retired 4-phase machinery (the four `phase-{1,2,3,4}-tdd.md` agent defs, `cairn-tdd-feature/SKILL.md`, `validate_phase_topology`'s regex over the four canonical slugs + role names + literal `Superpowers` token) AND the partially-built charter cycle. The downstream consumer (complex-rag-analysis, on a `.slice-system → .` symlink, ~917s pytest) inherits this mid-transition: its `.claude/settings.json` hook wiring, its agent-def discoverability (CC reads the consumer's `.claude/agents/`, NOT `.slice-system/.claude/...` — per the roadmap's documented migration delta), and its orchestrator all assume the 4-phase shape. The roadmap ALREADY documents an unrelated "Phase-1 dispatch defect — primary blocker" where the built-in sensitive-file gate denies `Write` to `.claude/.../intent.md` and the Bash-heredoc escape was severed — i.e., the consumer-facing dispatch path is *already* fragile, and the charter migration adds a methodology shape-change on top. INV-003's retirement removes the `validate_phase_topology` binding that the consumer's validator runs; if the consumer hasn't migrated its symlink + agent dirs + hook entries in lockstep, its validator either errors or silently stops enforcing. **Earliest signal:** the first consumer `/start-slice` (or charter equivalent) after the symlink update fails the way Lever-Z's did (retries + triager-escalate, per roadmap), OR the consumer's validator goes green-by-vacuity because the invariant it checked no longer exists. gh:#33's own SessionStart-skill work (item #1) collides here: it and the charter re-injection hook are the same `SessionStart`/`UserPromptSubmit` machinery (Gap 1) competing for the same event with no coordination ADR.

## S7 — Constraint-harvest worker mis-curates `constraints:`; a binding ADR is silently omitted and the cycle mutates against it. **[SCALE / CORRELATED-ERROR] — med × med — NEW (misalignment criterion #3)**

The §7 constraint-harvest worker is blind + disposable + same-model; it reads "the relevant ADRs" from a 40→60-ADR corpus and returns a CAPPED, CURATED `constraints:` set (the cap is prose, unenforced — journey trace A5). Curation under a cap is a recall problem, and recall over a large corpus is exactly where the same-model worker's blind spots bite (correlated-error: the harvest worker and the operator's mental model of "what's relevant" share training priors about salience). It omits an ADR that SHOULD bind — direction-§3's misalignment criterion #3, the "omitted an ADR that should have constrained the work" failure, which is also the N≥3 mechanism-deferral trigger. The build proceeds "compliant" with an incomplete `constraints:` set; the validator (structural, checks only *declared* constraints respected — F6) passes because the omitted ADR was never declared. The cycle mutates state against an invariant nobody told it about. Because mechanism-deferral ships NO smart-retrieval until N≥3 *independent* omissions (F8/§3; L-024), the first two omissions are absorbed as one-offs, and the discipline-only surfacing the design relies on (§7-tier-3, operator judges) depends on the operator independently remembering the ADR the worker forgot — which defeats the purpose of offloading the read. **Earliest signal:** the third superseded-or-contradicted-ADR ship within the counting window (tripping the N≥3 retrieval trigger) — by which point three cycles have already mutated state against omitted constraints. The single-catastrophic-instance fast-path (constraint-envelope §5, D2 R2 carve-out) is the only thing standing between this and silent corpus corruption, and the ADR may not have carved it out.

## Cross-cutting observations (for synthesis)

- **The headline value and the load-bearing identity point at DIFFERENT failure modes (S1+S2).** The charter cycle's headline ("goal-commitment vs reactivity") is a *within-cycle* property; cairn's claimed durable identity (the cliff, C1) is a *cross-cycle* property. The cycle mechanizes the former (weakly — Gap 1) and is structurally silent on the latter. The "complement" positioning canonizes a co-equal value the methodology cannot measure (S1) riding alongside a cliff it cannot address per-cycle (S2). This is the deepest pre-mortem finding: even if every mechanism ships perfectly, the methodology defends the wrong axis for its own stated identity.

- **build≠check is role-purity, not decorrelation (S3) — and the cycle has LESS decorrelation than what it supersedes.** The 4-phase machinery had four roles + the human role-reset half (C2). The charter cycle collapses to one same-model blind verifier. Per Kim et al. that verifier shares ~60% blind spots with the builder, and L-016 already fired on this exact shape downstream. The cleave the design calls its defensible core is its weakest correlated-error defense, and the ADR canonizes it as the mandatory invariant.

- **Three scenarios (S1, S3, S6) are independently sufficient to force re-supersession** within 12 months — the one-way-door cost (F1: 3 firm ADRs + INV-003) is paid against a 3-way risk of having to unwind it. R2 (F8) is not just "the surviving objection"; it is the pre-mortem's verdict that the supersession is under-evidenced for its blast radius.

- **The four journey-trace gaps are PRE-conditions, not the failures.** Gap 1 (no hook) → S1's unmeasurability + S5's bloat + S6's hook-collision. Gap 2 (no per-worker scope) → S4's concurrent corruption. Gap 3 (return accumulation) → compounds S3 (lead is also the gate). Gap 6 (in-cycle /decision) → compounds S2 (decision adversariality pulled into the build window). Fixing the four gaps mechanically does NOT close S1–S7; S1/S2/S3 survive a perfectly-built charter cycle.
