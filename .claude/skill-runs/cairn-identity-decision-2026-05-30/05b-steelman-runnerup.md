## JUDGMENT

### Is the firm supersession separable from shipping the primitive? — CONCRETE ANSWER

**The PRIMITIVE: yes, mechanically and textually separable.** `validate_phase_topology` (`validate_architecture.py:568-626`) is a closed three-way cross-reference over `role-topology.yaml` ⟷ `phase-skill-mapping.md` ⟷ `phase-N-*.md` filenames — it touches no charter file, no SKILL.md, no slash command. A charter primitive gets its own orthogonal `structural-parser` assertion (F6: bindable in the closed whitelist, no ADR-gate). The two invariants share no code path; the validator stays green. INV-003's operative text (`ARCHITECTURE.md:30`) is scoped to "every cairn-tdd **feature**," not "every work-unit," so a separately-named path consuming the primitive is not textually forbidden. **Position 1's "validator trips / live contradiction" claim is FALSE for the primitive alone.**

**The re-injection HOOK + "leading preset" framing: NOT cleanly separable.** The hook only functions if the charter is the live goal-state of the session — which is a de-facto methodology commitment. Naming the cycle "leading" beside a firm INV-003 ships two competing leading methodologies (worse than today's explicit co-equality). **Position 1 IS right against the lead's lean *as briefed*** (primitive + hook + leading-preset), and wrong only against a narrower decomposition (primitive-as-contract-object + cycle-as-documented-preset, hook deferred).

### Ranking of {decompose, defer-fully, commit-A-fully}, most defensible first

1. **DECOMPOSE — but only the disciplined form: ship the primitive as a contract object + supersede the 2 provisional ADRs + contribute the intent-file invariant; name the charter cycle as a *documented preset* (not "leading"); DEFER both the firm INV-003 supersession AND the re-injection hook to the later methodology ADR.** *Why:* it banks the one thing R1's death makes free (a buildable, validator-bound primitive doc-only can't deliver), pays only the minimum-irreversibility cost R2 endorses (2 provisional supersessions + 1 substrate invariant, which is what `04-c` shows is option-value-maximal), and — critically — defers the two pieces that cause the incoherence (the hook + the firm methodology claim) to the cycle where they belong. This collapses the gap between "decompose" and Approach C: the *defensible* decomposition IS Approach C plus an explicit "charter cycle is the front-running preset candidate, to be decided in a later methodology ADR." **The lead's lean is a genuine synthesis ONLY if it adopts this disciplined form; as briefed (hook now + "leading preset"), it is a comfortable dodge that ships the methodology's mechanism while disclaiming the methodology's firmness — the worst of both, exactly Position 1's teeth and Position 3's "half-believing is the worst posture."**

2. **COMMIT-A-FULLY.** *Why second, not third:* if the operator's reactivity signal is taken at face value and the lead is willing to own R2, A is *coherent* in a way the briefed decomposition is not — it pays the firm cost once, in one validator-green commit (the "one bet stated three times" is genuinely one supersession), and ships the hook with the conviction that justifies it. It ranks below decompose only because R2 is unanswered and S1/S3/S6 make re-supersession a live 12-month risk — but it beats defer-fully because deferral now forfeits the primitive, and it beats the *briefed* decomposition because at least A is internally consistent.

3. **DEFER-FULLY.** *Why last:* R1 is dead — "defer and write a lesson" no longer does the job cheaper, because doc-only cannot ship the new validator-bound primitive, so deferral now *destroys value* (the buildable primitive) rather than merely *delaying* it. And arc A arguably settled the substrate-is-identity half; deferring that specific claim is deferring a resolved question for option value. Defer-fully is the right answer only if you believe arc A's C5–C8 evidence is so weak that even committing the substrate as identity is premature — a defensible but maximalist read that the operator's D3.4 trigger and the dead R1 both cut against.

**Bottom line for the lead:** decomposition is the most defensible *destination*, but the lead's current *route* to it (hook now, cycle as "leading preset") imports the exact incoherence Position 1 weaponizes. The synthesis is real; the lean as briefed is one step too aggressive. Pull the hook and the "leading" label out of the now-ADR and decomposition becomes both coherent and option-value-maximal — and it stops being a dodge.
