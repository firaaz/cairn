## What

Land the M6 half of the M5+M6 milestone: ship a migration runbook plus a thin `scripts/migrate_from_symlink.sh` helper that takes the only existing `.slice-system → cairn` consumer (`complex-rag-analysis`) off the symlink and onto `/plugin install cairn@cairn-marketplace`; retire cairn-the-repo's symlink-era upgrade docs so future downstream consumers reach for plugin install only; resolve F1's leftover `<marketplace-url>` placeholders in `CONSUMER.md` and `README.md`; drop README's "fallback while plugin marketplace stabilises" framing so plugin install is the unambiguous primary path post-F3; and make the surviving validator-stdout-literal F1-followup at `CONSUMER.md:21-22` obviously-intentional via an in-line comment rewrite plus a `docs/roadmap.md` tracked-deferred entry. INV-011 is preserved verbatim — cairn-the-repo's own `.slice-system → .` self-symlink stays exactly as it is (D8). Three threads land together: M (runbook + helper), R (retire downstream-consumer docs + placeholder fixes + roadmap breadcrumb), P (INV-011 prose cite of F3).

## Why

ADR `m5-plugin-distribution-and-symlink-retire` D9 splits M5+M6 into three sequenced features (F1 packaging, F2 consumer-doc surface, F3 migration + retire). F1 (`6e25777`) and F2 (`8ca229f` + fixup `e3d088d`) shipped on `dev`; F3 closes the milestone by enacting the consumer-side cutover and removing the symlink-era guidance F1/F2 superseded. F3 absorbs the marketplace-URL fix in the same dispatch that retires the symlink. The validator-stdout-literal placeholder is **separately tracked** and stays under the replace branch, but a follow-up operator review of `33291ca` flagged that the bare F1-followup comment risks future-maintainer interpretation as "F3 forgot one" — so F3 also rewrites that comment to be obviously-intentional and lands a `docs/roadmap.md` entry as a discoverability breadcrumb. F3 covers `complex-rag-analysis` migration only (the sole existing symlink consumer), the cairn-the-repo doc retire, the F1-followup `<marketplace-url>` placeholder + README fallback-framing fixes, and the in-line CONSUMER.md:21 validator-stdout-comment rewrite + roadmap entry. **Script contract (`scripts/migrate_from_symlink.sh`).** Bash 3.2+, POSIX utilities only (`unlink`, `test`, `cat`, `git`, `printf`, `readlink`, `jq`). Exit codes:

**Force overrides (asymmetric, dedicated env vars per amendment 5).** The script supports two distinct force-mode env vars, each scoped to exactly one of the structural-default refusals:

- `CAIRN_MIGRATE_FORCE=1` — bypasses **exit 2 only** (quiescence). Force-mode prints a loud stderr warning naming Pre-mortem Scenario 6 and the orphan-state risk, then proceeds with exit 0. Setting `CAIRN_MIGRATE_FORCE=1` does **NOT** bypass exit 3 (cairn-self detection); the script still aborts.

On `CAIRN_MIGRATE_BREAK_INV011=1`, the script unlinks the symlink, applies the settings.json filter, and exits 0 (i.e., the rest of the migration runs). Env var name is **`CAIRN_MIGRATE_BREAK_INV011`** (literal; chosen here in this intent so Phase 2 tests against the exact string). ## Feature-Local Invariants

- **FLI-1 (D8 structural-default with explicit-override-only escape).** `scripts/migrate_from_symlink.sh` MUST refuse to run inside cairn-the-repo by self-symlink-target detection (`readlink .slice-system == "."` → exit 3) **by default**. The refusal is **structural-default**, not non-overridable: a dedicated env var `CAIRN_MIGRATE_BREAK_INV011=1` (and only that env var; `CAIRN_MIGRATE_FORCE=1` does NOT bypass exit 3) provides an explicit-override-only escape that prints a multi-line stderr block citing INV-011, D8, and `docs/ARCHITECTURE.md:91`. This matches the `ADR_EDITORIAL_FIX=1` precedent — structural default, dedicated override env var per refusal class. Phase 2 cases (c1)/(c2)/(c3) enforce.
- **FLI-2 (replace-branch atomicity).** Post-Phase-3, `git ls-files` MUST contain `docs/upgrading-from-symlink.md` AND MUST NOT contain `docs/upgrading-from-pre-compression.md`. Both halves of the swap are required; either alone is a defect.
- **FLI-3 (script exit-code surface).** The script's three exit codes (0, 2, 3) are the protocol-level contract Phase 2 tests against; new exit codes added by Phase 3 outside this set are scope-creep.
- **FLI-4 (no slash-command chaining).** The script MUST NOT attempt to invoke `/plugin marketplace add` or `/plugin install` itself; those are operator-bound session-restart-aware actions per Pre-mortem Scenario 2 defense (Section M.2 Step 7). Test (a) asserts stdout names them as the next manual step.
- **FLI-5 (POSIX-only — automated checks).** Bash 3.2 + POSIX utilities only; no `mapfile`, `readarray`, `[[` extended pattern matching beyond Bash 3.2 surface, or GNU-only flags. macOS default shell must run the script unmodified. Two automated checks enforce: (a) **shellcheck** in POSIX-strict shape (`-s sh` or `--shell=bash` with bash-3.2 directive — Phase 2 picks the form most likely to match the script's actual shebang) with zero-warnings asserted; (b) **dash runtime** pass — run the script under `/usr/bin/dash` against the four behavioural fixtures and verify the same exit codes and stderr/stdout substrings hold. Both checks gracefully `pytest.skip` / `xfail` if the corresponding binary is not on PATH so the dispatch does not false-fail on operator setup variance; Phase 4 sweep-notes records ran-vs-skipped per check, and the manual end-to-end (audit check 9) backstops missing tooling.
- **FLI-6 (envelope discipline).** All Phase 3 writes land within the plan's `envelope:` regex list (including the `caa7599`-expanded `^docs/roadmap\.md$`); the operator-envelope at `.claude/active-envelope.yaml` (if active) or `role_guard.py` per-phase allowlist enforces this — no scope creep into adjacent paths.
- **FLI-7 (literal-URL canonicalisation).** Every consumer-facing surface that names the marketplace install command MUST use the literal `https://github.com/firaaz/cairn` (sourced from `.claude-plugin/marketplace.json:12`) — no `<marketplace-url>` placeholder, no `<git-url>` token, no synonym. Surfaces in F3 scope: `README.md`, `CONSUMER.md`, `docs/upgrading-from-symlink.md`, and the script's stdout banner. Phase 4 audit check 8 enforces.
